# boostagency.uz — правила сайта

Astro 7, ветка `redesign`. Прод собирается на VPS из `/opt/boost-landing` (туда ставятся файлы этой ветки),
посты блога — `/opt/boost-landing/src/content/blog/*.md` (только на VPS).

## SEO — правила владельца (обязательны для всех текущих и новых страниц)

- **Title** каждой страницы кончается на « | Реклама в Ташкенте». Приписку ставит `pageTitle()` из
  `src/lib/title.ts` в `Base.astro` — в данных страниц и в seoTitle её не писать, хвост «— Boost! Agency» она заменяет.
  `scripts/seo-check.ts` останавливает сборку (`title-suffix`), если у страницы её нет.
- **Никаких внешних ссылок в постах блога** — ни блока «Источники», ни ссылок в тексте, ни адреса материала рерайта
  в коде страницы. Плагин сборки `src/lib/blog-links.ts` превращает ссылку на чужой сайт в текст.
- **Глоссарий**: термины — `src/data/glossary.ts` (одна статья на понятие, без дублей), страница каждого термина —
  `/glossary/<slug>/` из `src/data/glossary-pages/<группа>.json`; графики рисует `GlossaryVisual.astro` из данных.
  Первое упоминание термина в посте ведёт на его страницу (`blog-links.ts`); определения в постах не повторяем.
  Ссылки на несуществующие страницы терминов `seo-check.ts` считает ошибкой.
