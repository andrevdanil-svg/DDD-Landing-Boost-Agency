Генератор UTM-меток

Соберите корректные ссылки с utm_source, utm_medium и utm_campaign — по одной или сразу пачкой — и выгрузите список в XLSX.

Форма генератора

Площадка-источник трафика. Пишем латиницей, строчными, без пробелов.

Имя кампании для аналитики. Хороший формат: продукт_цель_период.

Отличает креативы и объявления внутри одной кампании.

Для контекста — ключ или динамический параметр площадки.

Автосборка имени кампании

Соберёт utm_campaign по формуле продукт_цель_источник_формат_оплата_таргетинг — так принято в агентствах для автоматического разбора отчётов. Поля необязательны, пустые пропускаются.

Как работают UTM-метки

Поля формы собирают ссылку по стандарту Google Analytics. Для каждой площадки подставляются корректные значения utm_source и utm_medium: cpc для контекста, cpm для баннерной рекламы, cpv для видео, cpa для конверсий. Массовый режим накапливает список и выгружает его в Excel одним файлом.

Стандартные значения utm_medium

cpc
контекстная и таргетированная реклама с оплатой за клик — Google Ads, Яндекс.Директ, Meta в режиме трафика.
cpm
баннерная и видео-реклама с оплатой за показы — медийка, programmatic, OLV.
cpa
оплата за действие — заявки, продажи, установки.
cpv
оплата за просмотр видео — YouTube, Rutube, VK Video.
email
рассылки, транзакционные письма, промо-письма.
social
органический трафик с соцсетей.
display
медийная реклама, если не хочется разделять cpm и cpc.
