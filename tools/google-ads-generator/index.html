Генератор кампании Google Ads из ключей

Из списка ключевых слов — готовая структура Responsive Search Ads: кампания, группы, типы соответствия, адаптивные объявления с макросами. На выходе — XLSX для Google Ads Editor.

Как пользоваться — за 4 шага

Коротко: вставьте список ключей → выберите типы соответствия → задайте шаблоны заголовков с макросами [KeyWord] → скачайте XLSX → импортируйте в Google Ads Editor и опубликуйте.

Каждая строка — отдельная группа объявлений. Через | можно задать свой URL и свой первый заголовок.

Отметьте один или несколько типов. Если выбрать несколько — ключ задублируется в разных типах соответствия.

Макросы в квадратных скобках подставляют текущий ключ. [KeyWord] — весь ключ с заглавной каждого слова, [word1] — первое слово.

Скачанный XLSX открывается в Google Ads Editor (бесплатная программа от Google). Редактор проверит данные и предложит залить всё в аккаунт.

Форма генератора

Если импортируете в существующую кампанию — скопируйте её точное название сюда.

Будет использован для всех ключей, где URL не указан в строке через |.

Пример: ламинат|https://example.uz/laminat|Купить ламинат в Ташкенте. Если URL не нужен, оставьте пусто: ключ||заголовок. Для только URL: ключ|url.

Типы соответствия

Если отмечено несколько — для каждого ключа создадутся несколько записей.

Адаптивное объявление

До 15 заголовков (30 знаков) и 4 описаний (90 знаков). Макросы:[KeyWord], [Keyword], [keyword] подставляют сам ключ в выбранном регистре,[word1]…[word5] — N-е слово ключа.

Подробная инструкция — для тех, кто впервые

Что такое Google Ads Editor и зачем он нужен

Google Ads Editor — бесплатная программа от Google для Windows и macOS, которая позволяет готовить кампании офлайн и заливать их в аккаунт пачкой. Через веб-интерфейс создавать 50 групп по одному ключу — долго; через Editor то же самое делается импортом одного файла.

Скачать: ads.google.com/intl/ru_uz/home/tools/ads-editor. Установили → запустили → привязали аккаунт Google Ads (попросит залогиниться).

Шаг 1. Готовим список ключей

Формат: один ключ на одну строку. Через | можно добавить два параметра:

  • ключ — просто ключ, URL и первый заголовок возьмутся из полей выше.
  • ключ|https://site.uz/страница — свой URL для этого ключа.
  • ключ|url|Купить в Ташкенте — ещё и первый заголовок, уникальный для этого ключа.
  • ключ||Купить в Ташкенте — пустой URL (возьмёт по умолчанию), но свой заголовок.

Каждый ключ станет отдельной группой объявлений — так контекстологи делают SKAG (Single Keyword Ad Group) для максимальной релевантности объявлений ключу.

Шаг 2. Выбираем типы соответствия

Три варианта, можно комбинировать:

Широкое
пишется как есть. Ловит синонимы, перефразировки, близкие по смыслу запросы. Самый широкий охват, но и больше нерелевантных показов. Хорошо работает с автоматическими стратегиями.
Фразовое
в кавычках. Запрос должен содержать смысл ключа — Google допускает перестановки слов и близкие формы, но не разрешает подмену темы.
Точное
в квадратных скобках. Только запросы с таким же смыслом. Самый узкий охват, но и самая высокая релевантность.

Чаще всего отмечают фразовое + точное — комбинация даёт хороший охват при контроле.

Шаг 3. Пишем шаблоны заголовков и описаний с макросами

Google Ads требует для одного адаптивного объявления минимум 3 заголовка (до 15, по 30 знаков) и 2 описания (до 4, по 90 знаков). Макросы в квадратных скобках подставляют текущий ключ или его часть:

[KeyWord]
подставляет ключ, первая буква каждого слова с заглавной. «купить ламинат» → «Купить Ламинат».
[Keyword]
только первая буква ключа заглавная. «купить ламинат» → «Купить ламинат».
[keyword]
ключ в нижнем регистре.
[word1]..[word5]
N-е слово ключа. Варианты [Word1] и [WORD1] — с капитализацией. Полезно, когда нужно только существительное из многословного ключа.

Шаг 4. Скачиваем XLSX и импортируем в Google Ads Editor

  1. Нажмите «Сгенерировать и скачать XLSX» — файл сохранится в папку загрузок.
  2. Откройте Google Ads Editor и выберите аккаунт в левом верхнем углу.
  3. Меню «Аккаунт» → «Импорт» → «Из файла» → выберите скачанный XLSX.
  4. Editor покажет диалог со списком того, что будет добавлено. Проверьте, что имя кампании совпадает с существующей (если импортируете в неё), иначе создастся новая.
  5. Нажмите «Подтвердить». Все кампании по умолчанию импортируются на паузе — это специально, чтобы вы могли проверить.
  6. Проверьте предпросмотр, снимите паузу с нужных кампаний и нажмите «Отправить» вверху — Editor отправит всё в аккаунт.

Что ещё важно знать

  • Ставка в XLSX проставлена условная (Max CPC = 1). Отрегулируйте в Editor или в веб-кабинете перед запуском.
  • Бюджет — 100 в день по умолчанию. Это заглушка, замените своим.
  • Статус — Paused. Включите кампанию, когда проверите.
  • Не превышайте 30 знаков в заголовках и 90 в описаниях — Google обрежет или откажет в показе.
  • Макросы раскрываются на нашей стороне — в XLSX уже лежат финальные тексты. Google-макросы вида {KeyWord:default} к этому инструменту отношения не имеют.
