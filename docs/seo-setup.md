# SEO: подтверждение сайта и мониторинг

Что нужно сделать один раз руками — у меня нет доступа к твоим аккаунтам Google, Яндекса и Facebook, но от этих шагов зависит, увидит ли вообще поисковик наш сайт.

## 1. Google Search Console (GSC)

**Что это и зачем.** GSC показывает, какие запросы приводят людей из Google, какие страницы индексируются, где 404 и ошибки. Без неё мы не знаем, как Google видит сайт.

**Как подключить:**

1. Открой https://search.google.com/search-console
2. «Добавить ресурс» → **URL-префикс** → `https://boostagency.uz` (не домен-ресурс, потому что у нас GH Pages — проще верификация).
3. Выбери способ «HTML-тег» → скопируй мета-тег вида `<meta name="google-site-verification" content="xxx..." />`.
4. Пришли мне content (значение между кавычками) — я вставлю в `src/layouts/Base.astro`, задеплою, после чего нажми «Подтвердить».
5. После подтверждения отправь карту сайта: раздел «Файлы Sitemap» → добавить `https://boostagency.uz/sitemap-index.xml`.

**Что проверять раз в 2 недели:**
- Раздел «Эффективность» → по каким запросам сайт показывается и кликается. Ищи запросы с высокими показами и низким CTR — это кандидаты на доработку title/description.
- Раздел «Индексирование» → «Страницы» → все 139 должны быть в «Проиндексированы». Если какие-то в «Не проиндексированы» — пришли мне, разберёмся.
- Раздел «Проверка URL» → для свежих страниц можно вручную запросить индексацию.

## 2. Яндекс.Вебмастер

**Что это и зачем.** Для рынка Узбекистана Яндекс важен не меньше Google — часть русскоязычной аудитории ищет в Яндексе, плюс он отвечает в Яндекс.Нейро.

**Как подключить:**

1. Открой https://webmaster.yandex.com (или .ru)
2. «Добавить сайт» → `https://boostagency.uz`
3. Выбери «Мета-тег» → скопируй `<meta name="yandex-verification" content="xxx..." />`.
4. Пришли мне content — вставлю в Base.astro, задеплою.
5. После подтверждения:
   - Раздел «Карта сайта» → добавить `https://boostagency.uz/sitemap-index.xml`
   - Раздел «Региональность» → назначить регион «Узбекистан» (критично для ранжирования в UZ).
   - Раздел «Переобход страниц» → добавить главные URL для быстрой индексации.

## 3. Google Business Profile (GBP)

**Что это и зачем.** Карточка в Google Maps и Поиске, когда ищут «рекламное агентство Ташкент». Главный источник «тёплых» клиентов для локальных услуг. Также влияет на LocalBusiness-schema (которая у нас уже есть) — координаты и график в GBP должны совпадать с `src/data/business.ts`.

**Как подключить:**

1. Открой https://business.google.com
2. Создай профиль «Boost! Agency» → категория «Рекламное агентство».
3. Укажи:
   - Юр.адрес и номер офиса (нужно от тебя — пришли, я заодно обновлю `src/data/business.ts`).
   - Телефон, email, Telegram.
   - График работы (сейчас в коде `Mo-Fr 09:00-18:00` — поправь, если другой).
   - Сайт: `https://boostagency.uz`
4. Google пришлёт открытку с кодом на физический адрес (10–14 дней) — вводи код, профиль станет видим в поиске.
5. Добавь фото офиса, команды, скриншоты дашбордов.

**После подтверждения** — пришли мне координаты офиса (широта/долгота из Google Maps), я обновлю `geo.latitude/longitude` в `src/data/business.ts` (сейчас стоит центр Ташкента).

## 4. Яндекс.Бизнес

**Что это и зачем.** Карточка в Яндекс.Картах. Для аудитории, ищущей через Яндекс и Яндекс.Нейро.

**Как подключить:**

1. Открой https://yandex.uz/sprav
2. «Добавить организацию» → заполнить те же данные, что в GBP (адрес, график, телефон, сайт).
3. Подтверждение — обычно звонком или кодом из приложения Яндекс.Карты.
4. Добавь фото, услуги с ценами (если готовы публиковать) или без цен — «от».

## 5. Bing Webmaster Tools

**Что это и зачем.** ChatGPT и Copilot (OpenAI/Microsoft) индексируются Bing. Для попадания в их ответы — важно, чтобы Bing видел сайт.

**Как подключить:**

1. https://www.bing.com/webmasters
2. «Добавить сайт» → импорт из Google Search Console (один клик, т.к. у нас уже будет подключён GSC).
3. Отправить sitemap: `https://boostagency.uz/sitemap-index.xml`.

## 6. Что я проверяю на каждом билде

Скрипт `scripts/seo-check.ts` (запускается автоматически в `./scripts/deploy.sh`):
- Все страницы имеют `<title>` 20–88 знаков.
- Все страницы имеют `<meta name="description">` 50–240 знаков.
- Все страницы имеют `canonical` (или `noindex`).
- Все страницы имеют валидный JSON-LD.
- Нет дублей title и description между разными URL.

Если найдёт **ошибки** — деплой остановится. **Предупреждения** не блокируют, но показываются в выводе.

Запуск вручную:
```bash
npm run build && npm run seo-check
```

## 7. Как измерять AI-видимость

Файл `research/seo/ai-visibility.csv` — журнал проверок. 20 контрольных запросов в начале файла, прогоняем раз в неделю через ChatGPT, Claude, Perplexity, Gemini и Яндекс.Нейро.

Что фиксировать:
- Упомянут ли `boostagency.uz` или бренд «Boost! Agency» в ответе?
- Если да: с какой страницы ИИ взял данные, на какой позиции в ответе?
- Если нет: кого ИИ рекомендует вместо нас (Ledokol, Cornerstone, другие)?

Через 3 месяца появится статистика — какие запросы покрываются, какие нет. Под те, что не покрываются, — дорабатываем страницы или добавляем контент.
